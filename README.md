# 小马利亚魔法塔罗 · Equestria Tarot

小马宝莉主题的塔罗牌网站：在小镇夜景里写下问题、翻开卡牌，让六位小马从各自的视角为你解读。免费、无需登录；模型不参与抽牌与牌义，只做解读润色。

当前正式卡组「版本2」共 78 张：**紫悦**领航 22 张大阿卡纳，**云宝**（权杖）、**柔柔**（圣杯）、**珍奇**（宝剑）、**苹果嘉儿**（星币）各守一门花色，四张王牌由**碧琪**欢展开席；牌义结合小马利亚的场景与角色故事定制。

`Next.js 16` · `React 19` · `TypeScript` · `原生 CSS` · `SQLite`

**在线体验**：<http://43.142.102.75:3100/>

## 功能亮点

- **版本2卡组** — 78 张牌义全部结合小马利亚世界观定制：关键词、正逆位解读、小行动与思考题
- **三牌占卜** — 处境 / 行动 / 方向，提问 → 抽牌 → 翻牌 → 选一位小马获得 AI 流式解读；逆位可关闭
- **今日一牌** — 按本地日期固定，同一天结果不变
- **星辰图鉴** — 78 张牌的卡面、搜索、正逆位牌义
- **魔法手札** — 本地珍藏每次解读的完整快照（最多 50 条），支持文本导出
- **六马视角** — 紫悦的梳理、碧琪的灵感、柔柔的关怀、云宝的行动、珍奇的自我价值、苹果嘉儿的现实
- **隐私友好** — AI Key 加密存本地数据库，抽牌与牌义完全不经过模型

## 本地操作

在`pony-tarot/`目录运行：

```powershell
npm.cmd install
npm.cmd run ai:setup   # 生成本地密钥加密Key（写入.env.local，不入库）
npm.cmd run dev        # http://127.0.0.1:3000
```

检查并打包最新版本：

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run deploy:prepare
npm.cmd run deploy:package
```

部署包由bsdtar生成，使用Linux可识别的路径分隔符；不包含本机或服务器的Key、数据库。服务器密钥和数据独立保存在`/home/ubuntu/pony-tarot-data/`，更新程序时沿用。

## 版本管理

Git 仓库在本目录根，`.gitignore` 排除五类内容：密钥与运行时数据（`.env.local`、`.runtime/*.sqlite`）、依赖与构建产物（`node_modules`、`.next`、`out/`、`deploy-package/`、zip 与日志）、开源参考快照（`tarot-main/` 等三个目录）、卡面原图（`卡牌版本1/`、`卡牌版本2/`，网页使用 `pony-tarot/public/` 下已压缩的 WebP，原图仅留在本机）、ZCode 会话目录（`.zcode/`）。推送 GitHub 前先 `git status` 复核没有密钥类文件被跟踪。
